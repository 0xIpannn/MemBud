## Rendering

```sh
python3 paper/tools/make_figures.py
```

The script writes the SVGs, renders the PNGs at 2x with `rsvg-convert -z 2` and the PDFs with `rsvg-convert -f pdf`, then rewrites this index. `rsvg-convert` 2.63 rejects the `-w 2x` spelling, so `-z 2` is used for the same 2x pixel dimensions.

Captions are the exact captions from the Chapter 3 manuscript (paragraphs 009, 025, 096, 103, 106, 155, 166, 196, 207 of `.tmp-lead/docx/chapter3.txt`).
